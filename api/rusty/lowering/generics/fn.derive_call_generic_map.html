Expand description

Derives the generic bindings of a call to a (non-builtin) generic function from its concrete arguments alone; candidates that are themselves still generic carry no vote. Returns None when the callee is not a generic function subject to monomorphization. Callers that must wait for nested generic calls to resolve first (like the lowering phase itself) check that separately; consumers that resolve incrementally (like the CFC temporary inference) take the partial evidence as-is.
