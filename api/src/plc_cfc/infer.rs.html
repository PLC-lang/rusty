1//! Type resolution for generic-typed CFC temporaries.
2//!
3//! CFC ensures that no block is called more than once within a cycle. However, sometimes the output variable
4//! or the return value of a block may need to be consumed by multiple consumers. For example think of
5//! something like
6//! ```text
7//!         myAdd (0)
8//!       +--------------------+
9//! x --> | a            myAdd | --+--> result1 (1)
10//! y --> | b                  |   '--> result2 (2)
11//!       +--------------------+
12//! ```
13//!
14//! There are two ways to fix this: (1) When dealing with stateful POUs directly access the member fields or
15//! (2) when dealing with stateless POUs (functions, methods) create a "temporary" variable, persist the
16//! return/output value in there and pass it to the consumers.
17//!
18//! This case distinction is necessary because a stateful POU persists its outputs, they live in the
19//! instance and can be read back as `instance.member` at any time. A stateless POU has no instance thus its
20//! outputs vanish the moment the call returns, and calling it once per consumer instead would duplicate
21//! side effects (and possibly yield different results). So the caller has to persist the value itself.
22//!
23//! However, the stateless approach brings its own challenges. Let's inspect a simple example first to get
24//! an understanding of the "temporary" variable creation:
25//! ```text
26//!         myAdd (0)
27//!       +--------------------+
28//! x --> | a            myAdd | --> result (1)
29//! y --> | b          doubled | --> d (2)
30//!       +--------------------+
31//! ```
32//! which transpiles into
33//! ```iecst
34//! VAR
35//!     __out_myAdd_1   : DINT;
36//!     __out_doubled_1 : DINT;
37//! END_VAR
38//!     __out_myAdd_1 := myAdd(a := x, b := y, doubled => __out_doubled_1);
39//!     result := __out_myAdd_1;
40//!     d := __out_doubled_1;
41//! ```
42//! The temporaries simply take the callee's declared types, `DINT` here. Now let's take that same example,
43//! but make it generic, i.e. `myAdd<T: ANY_NUM> : T` where the inputs, the output variable and the return
44//! value all bind `T`. This transpiles literally into
45//! ```iecst
46//! VAR
47//!     __out_myAdd_1   : __myAdd__T;
48//!     __out_doubled_1 : __myAdd__T;
49//! END_VAR
50//!     __out_myAdd_1 := myAdd(a := x, b := y, doubled => __out_doubled_1);
51//!     result := __out_myAdd_1;
52//!     d := __out_doubled_1;
53//! ```
54//!
55//! The issue being, at transpile time we do not have enough type information to query the concrete type the
56//! given "temporary" variable will receive. Instead, we have to resolve them ourselves which this module is
57//! responsible for.
58//!
59//! The workflow can be described as collecting all generic variables that have not been resolved yet,
60//! annotate the unit once, visit the assignment sites and try to derive the generic variables type if
61//! possible based on the context. For example, given a chain of two `myAdd` calls, if we visit
62//! `__out_myAdd_1 := ...` in
63//! ```iecst
64//! __out_myAdd_1 := myAdd(a := x, b := y, doubled => );                // x, y : INT
65//! __out_myAdd_5 := myAdd(a := __out_myAdd_1, b := z, doubled => );    // z : DINT
66//! ```
67//! then the type is derivable by simply asking the annotator for the type of the call, `x` and `y` decide
68//! `T = INT`. At the same time `__out_myAdd_5 := ...` is not derivable yet because it references a generic
69//! variable that has not been resolved yet: deriving now would consider `z` alone and could disagree with
70//! the final answer, so it has to wait one round until `__out_myAdd_1`'s resolved type is published to the
71//! index and a fresh annotation can pick it up.
72//!
73//! This workflow is repeated until all generic variables have been resolved or we've hit a point where the
74//! remaining variables are genuinely not resolvable. Not resolvable being something like a generic output
75//! fed back into nothing but its own generic inputs, e.g.
76//! ```text
77//!          myAdd (0)
78//!        +--------------------+
79//!   .--> | a            myAdd | --+--> acc (1)
80//!   +--> | b                  |   |
81//!   |    +--------------------+   |
82//!   '-----------------------------'
83//! ```
84//!
85//! The downside of doing this with a participant rather than a dedicated IR is the round-based looping. If
86//! we assume a unit has a very long chain of generic blocks like the following example then we have to
87//! assume a total of (worst case) N rounds. One per link, because each link only becomes derivable once its
88//! predecessor's type is published. Resolved types are published in place (`Index::update_member_type`), so
89//! a round only costs one annotation of this unit rather than a re-index of the whole project.
90//! ```text
91//!       +------------+     +------------+     +------------+
92//! x --> | a      out | --> | a      out | --> | a      out | --> ...
93//! y --> | b          | z ->| b          | w ->| b          |
94//!       +------------+     +------------+     +------------+
95//! ```

110/// Runs one round; returns whether any temporary was patched, in both the
111/// unit's declarations and the index, meaning another round could make
112/// progress.
113pub fn infer_temporary_types(unit: &mut CompilationUnit, index: &mut Index, ids: IdProvider) -> bool {
114    // Temporaries whose declared type is still generic, the unknowns.
115    let open = open_temporaries(unit, index).map(|variable| variable.name.clone()).collect::<HashSet<_>>();
116    if open.is_empty() {
117        return false;
118    }
119    log::trace!("round starts with {} open temporaries: {:?}", open.len(), {
120        let mut names = open.iter().collect::<Vec<_>>();
121        names.sort();
122        names
123    });
124
125    // Annotate this unit only; declarations patched in earlier rounds are
126    // already published to the index, so the answers improve round over round.
127    let (annotations, ..) = TypeAnnotator::visit_unit(index, unit, ids);
128
129    // Harvest the concrete type each open temporary's capture resolved to.
130    let mut resolved = HashMap::new();
131    for statement in unit.implementations.iter().flat_map(|implementation| &implementation.statements) {
132        // `callee(...)`, bare or behind `temporary := callee(...)`.
133        let (call_node, return_capture) = match statement.get_stmt() {
134            AstStatement::Assignment(assignment) => {
135                (assignment.right.as_ref(), assignment.left.get_flat_reference_name())
136            }
137            AstStatement::CallStatement(_) => (statement, None),
138            _ => continue,
139        };
140        let AstStatement::CallStatement(call) = call_node.get_stmt() else { continue };
141
142        // `temporary := callee(...)`: the temporary takes the call's annotated (return) type.
143        if let Some(name) = return_capture {
144            if open.contains(name) && is_ready(call, name, &open) {
145                match resolved_type(annotations.get_type(call_node, index), call, &annotations, index) {
146                    Some(data_type) => {
147                        log::trace!("`{name}` resolved to `{data_type}` (return capture)");
148                        resolved.insert(name.to_string(), data_type);
149                    }
150                    None => log::trace!("`{name}`: call has no concrete annotation"),
151                }
152            }
153        }
154
155        // `parameter => temporary`: the temporary takes the output parameter's annotated type.
156        for argument in arguments(call) {
157            let AstStatement::OutputAssignment(inner) = argument.get_stmt() else { continue };
158            let Some(name) = base_reference(&inner.right) else { continue };
159            if open.contains(name) && is_ready(call, name, &open) {
160                match resolved_type(annotations.get_type(&inner.left, index), call, &annotations, index) {
161                    Some(data_type) => {
162                        log::trace!("`{name}` resolved to `{data_type}` (output capture)");
163                        resolved.insert(name.to_string(), data_type);
164                    }
165                    None => log::trace!("`{name}`: output parameter has no concrete annotation"),
166                }
167            }
168        }
169    }
170
171    // Patch the resolved declarations in place and publish them to the index,
172    // making them visible to the next round's annotation without a re-index.
173    for pou in &mut unit.pous {
174        for variable in pou.variable_blocks.iter_mut().flat_map(|block| block.variables.iter_mut()) {
175            if let Some(data_type) = resolved.get(&variable.name) {
176                variable.data_type_declaration =
177                    DataTypeDeclaration::reference(data_type, variable.location.clone());
178                index.update_member_type(&pou.name, &variable.name, data_type);
179            }
180        }
181    }
182
183    log::trace!("round resolved {} of {} temporaries", resolved.len(), open.len());
184    !resolved.is_empty()
185}

187/// One diagnostic per temporary the fixed point could not resolve, reported
188/// in terms of the block the user placed, not the generated temporary.
189pub fn unresolved_temporaries(unit: &CompilationUnit, index: &Index) -> Vec<Diagnostic> {
190    open_temporaries(unit, index)
191        .map(|variable| {
192            let block = producer(unit, &variable.name).unwrap_or(variable.name.as_str());
193            log::trace!("`{}` never resolved; reporting `{block}` as unresolvable", variable.name);
194            Diagnostic::unresolved_generic_output(block, variable.location.clone())
195        })
196        .collect()
197}

199// Declarations whose type is still generic, the unknowns.
200fn open_temporaries<'unit>(
201    unit: &'unit CompilationUnit,
202    index: &'unit Index,
203) -> impl Iterator<Item = &'unit Variable> {
204    unit.pous.iter().flat_map(|pou| &pou.variable_blocks).flat_map(|block| &block.variables).filter(
205        |variable| {
206            variable.data_type_declaration.get_name().is_some_and(|name| {
207                matches!(index.get_type_information_or_void(name), DataTypeInformation::Generic { .. })
208            })
209        },
210    )
211}

213/// May we trust the annotator about this call this round? Not yet if it reads
214/// a *foreign* open temporary (partial evidence, wait for that producer), and
215/// never if nothing external feeds it (left open, reported as unresolvable).
216/// Reading its *own* output is fine; the external inputs decide the type.
217fn is_ready(call: &CallStatement, own: &str, open: &HashSet<String>) -> bool {
218    let mut external = false;
219    for argument in arguments(call) {
220        // Only input values feed candidates; output captures receive.
221        let value = match argument.get_stmt() {
222            AstStatement::Assignment(inner) => &inner.right,
223            AstStatement::OutputAssignment(_) => continue,
224            _ => argument,
225        };
226
227        match base_reference(value) {
228            Some(temporary) if open.contains(temporary) => {
229                // Another producer still open; defer.
230                if temporary != own {
231                    log::trace!("`{own}`: deferred, waits for `{temporary}`");
232                    return false;
233                }
234            }
235            _ => external |= !value.is_empty_statement(),
236        }
237    }
238
239    if !external {
240        log::trace!("`{own}`: no external input, cannot resolve");
241    }
242    external
243}

245/// The concrete type behind an annotated capture: the annotator's answer when it is already
246/// concrete (see [`concrete_type`]). When it is still generic — the annotator no longer resolves
247/// non-builtin generic calls, that happens in the later `GenericLowerer` phase — the binding is
248/// derived from the call's concrete arguments instead; arguments that are themselves still
249/// generic carry no vote, so a resolved external input decides even in feedback shapes.
250fn resolved_type(
251    data_type: Option<&DataType>,
252    call: &CallStatement,
253    annotations: &dyn AnnotationMap,
254    index: &Index,
255) -> Option<String> {
256    if let Some(concrete) = concrete_type(data_type, index) {
257        return Some(concrete);
258    }
259
260    // Look up which generic symbol the still-generic capture binds, and what the call's concrete
261    // arguments derived for it.
262    let DataTypeInformation::Generic { generic_symbol, .. } = data_type?.get_type_information() else {
263        return None;
264    };
265    let generic_map = derive_call_generic_map(index, annotations, call)?;
266    let derived = generic_map.get(generic_symbol)?.derived_type();
267
268    // A type absent from the global index would dangle after the re-index.
269    index.find_effective_type_by_name(derived).map(|it| it.get_name().to_string())
270}

272// The annotator's answer, if usable: generic/void results are still undecided,
273// and a type absent from the global index would dangle after the re-index.
274fn concrete_type(data_type: Option<&DataType>, index: &Index) -> Option<String> {
275    let data_type = data_type?;
276
277    let generic = matches!(data_type.get_type_information(), DataTypeInformation::Generic { .. });
278    (!generic && !data_type.is_void() && index.find_effective_type_by_name(data_type.get_name()).is_some())
279        .then(|| data_type.get_name().to_string())
280}

282// The callee whose return or output is captured into the given temporary.
283fn producer<'unit>(unit: &'unit CompilationUnit, temporary: &str) -> Option<&'unit str> {
284    unit.implementations.iter().flat_map(|implementation| &implementation.statements).find_map(|statement| {
285        // `callee(...)`, bare or behind `temporary := callee(...)`.
286        let (call_node, return_capture) = match statement.get_stmt() {
287            AstStatement::Assignment(assignment) => {
288                (assignment.right.as_ref(), assignment.left.get_flat_reference_name())
289            }
290            _ => (statement, None),
291        };
292        let AstStatement::CallStatement(call) = call_node.get_stmt() else { return None };
293
294        let captures = return_capture == Some(temporary)
295            || arguments(call).iter().any(|argument| match argument.get_stmt() {
296                AstStatement::OutputAssignment(inner) => base_reference(&inner.right) == Some(temporary),
297                _ => false,
298            });
299
300        captures.then(|| call.operator.get_flat_reference_name()).flatten()
301    })
302}

304// `NOT (x)` -> `x`: the referenced name behind negation/parentheses.
305fn base_reference(node: &AstNode) -> Option<&str> {
306    match node.get_stmt() {
307        AstStatement::ParenExpression(inner) => base_reference(inner),
308        AstStatement::UnaryExpression(UnaryExpression { value, .. }) => base_reference(value),
309        _ => node.get_flat_reference_name(),
310    }
311}
