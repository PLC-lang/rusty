1//! Lowering of method calls into indirect calls through virtual tables
2//!
3//! This module is responsible for lowering / transforming method calls into method calls through the
4//! virtual table (for information regarding virtual tables refer to [`crate::lowering::polymorphism::table`]). In a
5//! nutshell it will transform a method call such as `ptr^.foo()` into `__vtable_Fb#(ptr^.__vtable^).foo^(ptr^)`.
6//!
7//! However, not all method calls must be lowered but rather the following cases:
8//!
9//! # 1. Method calls within methods (and function block bodies)
10//! The reason we want to lower all method calls within (other) methods is for the fact that a non
11//! overridden method may make use of an overridden method. For example consider
12//! ```text
13//! FUNCTION_BLOCK A
14//!     METHOD getName: STRING
15//!         getName := 'A';
16//!     END_METHOD
17//!
18//!     METHOD printName
19//!         printf('name = %s$N', ADR(getName()));
20//!     END_METHOD
21//! END_FUNCTION_BLOCK
22//!
23//! FUNCTION_BLOCK B EXTENDS A
24//!     METHOD getName: STRING
25//!         getName := 'B';
26//!     END_METHOD
27//!
28//!     METHOD persistName
29//!         // Persist name to some file
30//!     END_METHOD
31//! END_FUNCTION_BLOCK
32//!
33//! FUNCTION main
34//!     VAR
35//!         instanceA: A;
36//!         instanceB: B;
37//!
38//!         refInstanceA: POINTER TO A;
39//!     END_VAR
40//!
41//!     refInstanceA := ADR(instanceA);
42//!     refInstanceA^.printName(); // Calls `A::printName` which calls `A::getName` yielding "name = A"
43//!
44//!     refInstanceA := ADR(instanceB);
45//!     refInstanceA^.printName(); // Calls `A::printName` which calls `B::getName` yielding "name = B"
46//! END_FUNCTION
47//! ```
48//!
49//! As described in the main function, the calls to `printName` must happen at runtime. Were that not the case
50//! then `printName` in A would resolve to `A::getName` at compile time, yielding an incorrect result for the
51//! second `refInstanceA^.printName()` call. Lowering the call to `printName` would result in
52//! `printf('name = %s$N', ADR(__vtable_A#(THIS^.__vtable^).getName^(THIS^))`.
53//!
54//! Method calls within methods of a program are not lowered. A program cannot be extended, so each of its
55//! method calls has exactly one target and remains a direct call.
56//!
57//! # 2. Method calls through a pointer variable pointing to a class or function block
58//! Essentially what is illustrated in 1. within the main function, consider:
59//!
60//! ```text
61//! FUNCTION main
62//!     VAR
63//!         name: STRING;
64//!         instanceA: A;
65//!         instanceB: B;
66//!
67//!         refInstanceA: POINTER TO A;
68//!     END_VAR
69//!
70//!     refInstanceA := ADR(instanceA);
71//!     name := refInstanceA^.getName(); // Calls `A::getName` yielding "name = A"
72//!
73//!     refInstanceA := ADR(instanceB);
74//!     name := refInstanceA^.getName(); // Calls `B::getName` yielding "name = B"
75//! END_FUNCTION
76//! ```
77//!
78//! While this is a simple example, and in theory compilers would be able to derive the correct method calls
79//! at compile time with some statical analysis, our compiler today is not able to do that. Specifically it
80//! does not know that the second `refInstanceA` variable is pointing at `B` and the pointer call could be
81//! simplified into a direct call to `B::getName()`. Instead, it relies on dynamic dispatch for a correct code
82//! execution. Again, this is done by accessing the virtual table and calling the function pointer behind it.
83//! In terms of ST code we would transform the calls into `__vtable_A#(refInstanceA^.__vtable^).getName^(refInstanceA^)`.
84//!
85//!
86//! One final thing to note, while the casting of the virtual tables into concrete types is not really
87//! interesting per-se, the upcasting from a child to its parent virtual table should at least be mentioned.
88//! That is, as long as the virtual table definitions are compatible, upcasting can be performed without any
89//! issues. Compatible here refers to the fact that the order of the member fields must be constant. More
90//! specifically, the methods must be defined in "ancestral hierarchical order". To illustrate with the
91//! previous examples, assume we have
92//! ```text
93//! TYPE __vtable_A:
94//!     STRUCT
95//!         getName: __FPOINTER TO A.getName := ADR(A.getName);
96//!         printName: __FPOINTER TO A.printName := ADR(A.printName);
97//!     END_STRUCT
98//! END_TYPE
99//!
100//! TYPE __vtable_B:
101//!     STRUCT
102//!         getName: __FPOINTER TO B.getName := ADR(B.getName);             // Overridden
103//!         printName: __FPOINTER TO A.printName := ADR(A.printName);       // Inherited
104//!         persistName: __FPOINTER TO B.persistName := ADR(B.persistName); // New
105//!     END_STRUCT
106//! ```
107//!
108//! We can safely cast from B to A's virtual table because the layout is compatible and it would result in
109//! `persistName` to be cut off in the cast. Were that not the case, e.g. if `getName` were to be swapped with
110//! `persistName` then the call to `getName` would silently result in calling `persistName`.

129pub struct PolymorphicCallLowerer<'a> {
130    pub ids: IdProvider,
131    pub index: &'a Index,
132    pub annotations: &'a AnnotationMapImpl,
133
134    pub in_method_or_function_block: Option<String>,
135}

137impl<'a> AstVisitorMut for PolymorphicCallLowerer<'a> {
138    fn visit_implementation(&mut self, implementation: &mut plc_ast::ast::Implementation) {
139        if implementation.location.is_internal() {
140            return;
141        }
142
143        self.in_method_or_function_block = match &implementation.pou_type {
144            PouType::FunctionBlock => Some(implementation.name.clone()),
145            PouType::Method { parent, .. } if self.has_virtual_table(parent) => Some(parent.clone()),
146            _ => None,
147        };
148
149        for statement in &mut implementation.statements {
150            statement.walk(self);
151        }
152
153        self.in_method_or_function_block = None;
154    }
155
156    fn visit_call_statement(&mut self, node: &mut plc_ast::ast::AstNode) {
157        // When dealing with a function call such as `ref^.foo()` we have to perform several steps to lower
158        // it into a form that can be executed by the codegen without any intervention from our side, namely:
159        // 1. We must add the expression (excluding the method name) as the first argument to the call
160        //    -> ref^.foo(ref^)
161        // 2. We must access the virtual table of the instance, a VOID pointer
162        //    -> ref^.__vtable^.foo(ref^)
163        // 3. We must cast the virtual table access into a concrete type
164        //    -> __vtable_<POU_NAME>#(ref^.__vtable^).foo(ref^)
165        // 4. We must dereference the method call, which is a function pointer
166        //    -> __vtable_<POU_NAME>#(ref^.__vtable^).foo^(ref^)
167        //
168        // The final result transforms ref^.foo() into __vtable_<POU_NAME>#(ref^.__vtable^).foo^(ref^)
169        let prev = node.as_string();
170        let AstStatement::CallStatement(CallStatement { operator, parameters }) = &mut node.stmt else {
171            unreachable!();
172        };
173
174        // We need to walk the parameters before deciding to potentially stop here, because parameters may
175        // also contain polymorphic calls that need to be lowered, e.g. `functionCall(methodCall())`
176        if let Some(ref mut parameters) = parameters {
177            parameters.walk(self);
178        }
179
180        if self.calls_into_program(operator) || !self.is_polymorphic_call_candidate(operator) {
181            return;
182        };
183
184        let unit_name = match self.in_method_or_function_block {
185            Some(ref name) => name.clone(),
186            None => match operator.get_base_ref_expr() {
187                Some(base) => {
188                    // When dealing with e.g. __main_myVariable
189                    let ty = self.annotations.get_type(base, self.index).unwrap();
190                    self.index.find_elementary_pointer_type(ty.get_type_information()).get_name().to_string()
191                }
192
193                None => {
194                    let ty = self.annotations.get_type(operator, self.index).unwrap();
195                    self.index.find_elementary_pointer_type(ty.get_type_information()).get_name().to_string()
196                }
197            },
198        };
199
200        log::trace!("lowering {}", operator.as_string());
201
202        // Pre-steps, add `__body` call when dealing with a direct function block and...
203        self.maybe_patch_body_operator(operator);
204        log::trace!("-1: {}", operator.as_string());
205
206        // ...add a `THIS^` base when dealing with method calls without a base, e.g. `foo()`
207        self.maybe_patch_this_base(operator);
208        log::trace!("0: {}", operator.as_string());
209
210        // Step 1: Add the expression (excluding the method name) as the first argument to the call
211        self.patch_instance_argument(operator, parameters);
212        log::trace!("1: {}", operator.as_string());
213
214        // Step 2: Patch a dereferenced virtual table access into the operator
215        self.patch_vtable_access(operator);
216        log::trace!("2: {}", operator.as_string());
217
218        // Step 3: Patch the virtual table cast into the operator
219        self.patch_vtable_cast(operator, &unit_name);
220        log::trace!("3: {}", operator.as_string());
221
222        // Step 4: Patch the method call to a dereferenced call
223        self.patch_method_call_deref(operator);
224        log::trace!("4: {}", operator.as_string());
225
226        log::debug!("converted `{}` into `{}`", prev, node.as_string());
227    }
228}

230impl<'a> PolymorphicCallLowerer<'a> {
231    pub fn new(ids: IdProvider, index: &'a Index, annotations: &'a AnnotationMapImpl) -> Self {
232        PolymorphicCallLowerer { ids, index, annotations, in_method_or_function_block: None }
233    }
234
235    pub fn lower(&mut self, units: &mut [CompilationUnit]) {
236        for unit in units {
237            self.visit_compilation_unit(unit);
238        }
239    }
240
241    /// Returns true if the given POU is a function block or class, the only POUs with a virtual table.
242    fn has_virtual_table(&self, pou_name: &str) -> bool {
243        self.index.find_pou(pou_name).is_some_and(|pou| pou.is_function_block() || pou.is_class())
244    }
245
246    /// Returns true if the given call operator runs the body or a method of a program, e.g. `refProg()` or
247    /// `refProg.foo()`. A program has no virtual table, so these calls stay direct.
248    fn calls_into_program(&self, operator: &AstNode) -> bool {
249        let is_method = self.annotations.get_type(operator, self.index).is_some_and(DataType::is_method);
250        let instance = if is_method { operator.get_base_ref_expr() } else { Some(operator) };
251
252        instance
253            .and_then(|it| self.annotations.get_type(it, self.index))
254            .and_then(|ty| self.index.find_pou(ty.get_name()))
255            .is_some_and(PouIndexEntry::is_program)
256    }
257
258    /// Returns true if the given AST node is a candidate that needs to be lowered into a polymorphic call.
259    fn is_polymorphic_call_candidate(&self, operator: &AstNode) -> bool {
260        // We do not want to lower THIS and SUPER access, e.g. {THIS,SUPER}^() or {THIS,SUPER}^.foo()
261        if operator.is_super_or_super_deref()
262            || operator.get_base_ref_expr().is_some_and(AstNode::is_super_or_super_deref)
263            || operator.is_this()
264            || operator.is_this_deref()
265        {
266            return false;
267        }
268
269        if self.annotations.get(operator).is_some_and(|opt| opt.is_fnptr()) {
270            return false;
271        }
272
273        // Case 1 (Method call within methods or function block bodies)
274        if self.in_method_or_function_block.is_some()
275            && self.annotations.get_type(operator, self.index).is_some_and(DataType::is_method)
276            // Only lower something alike `THIS^.foo()` or `foo()` as opposed to `SUPER^.foo()` or `instanceFb.foo()`
277            && (operator.get_base_ref_expr().is_none() || operator.get_base_ref_expr().is_some_and(|opt| opt.is_this()))
278        {
279            return true;
280        }
281
282        // Case 2 (Method invocation via a pointer to a class or function block instance)
283        let AstStatement::ReferenceExpr(ReferenceExpr { access, base }) = &operator.stmt else {
284            return false;
285        };
286
287        match (access, base) {
288            // Dealing with `MyFbRef^.foo()`
289            (ReferenceAccess::Member(_), Some(base)) => self.is_polymorphic_call_candidate(base),
290
291            // Dealing with `MyFbRef^()`
292            (ReferenceAccess::Deref, Some(base)) => {
293                if self.annotations.get(operator).is_some_and(StatementAnnotation::is_fnptr) {
294                    return false;
295                };
296
297                let info = self.annotations.get_type_or_void(base, self.index).get_type_information();
298                let DataTypeInformation::Pointer { inner_type_name, .. } = info else {
299                    return false;
300                };
301
302                let inner_pointer_type = self.index.get_type_information_or_void(inner_type_name);
303                inner_pointer_type.is_class() || inner_pointer_type.is_function_block()
304            }
305
306            // Auto-deref, e.g. `refInstance: REFERENCE TO ...`
307            (ReferenceAccess::Member(member), None) => {
308                self.annotations.get(member).is_some_and(StatementAnnotation::is_reference_to)
309            }
310
311            _ => false,
312        }
313    }
314
315    fn maybe_patch_body_operator(&mut self, operator: &mut AstNode) {
316        if !self
317            .annotations
318            .get_type(operator, self.index)
319            .is_some_and(|opt| opt.information.is_function_block())
320        {
321            return;
322        }
323
324        let old_base = std::mem::take(operator);
325        let mut new_base = AstFactory::create_member_reference(
326            AstFactory::create_identifier("__body", SourceLocation::internal(), self.ids.next_id()),
327            Some(old_base),
328            self.ids.next_id(),
329        );
330
331        std::mem::swap(operator, &mut new_base);
332    }
333
334    fn maybe_patch_this_base(&mut self, operator: &mut AstNode) {
335        if !(self.in_method_or_function_block.is_some() && operator.get_base_ref_expr().is_none()) {
336            return;
337        }
338
339        let this_node = Box::new(AstFactory::create_deref_reference(
340            AstFactory::create_this_reference(SourceLocation::internal(), self.ids.next_id()),
341            self.ids.next_id(),
342            SourceLocation::internal(),
343        ));
344
345        operator.get_ref_expr_mut().unwrap().base.replace(this_node);
346    }
347
348    fn patch_instance_argument(&mut self, operator: &mut AstNode, parameters: &mut Option<Box<AstNode>>) {
349        // foo.bar()
350        // ^^^ base
351        let base = self.maybe_cast_instance(operator);
352
353        match parameters {
354            None => {
355                parameters.replace(Box::new(base));
356            }
357
358            Some(ref mut expr) => match &mut expr.stmt {
359                AstStatement::ExpressionList(expressions) => {
360                    expressions.insert(0, base);
361                }
362
363                _ => {
364                    let mut expressions = Box::new(AstFactory::create_expression_list(
365                        vec![base, std::mem::take(expr)],
366                        SourceLocation::internal(),
367                        self.ids.next_id(),
368                    ));
369
370                    std::mem::swap(expr, &mut expressions);
371                }
372            },
373        }
374    }
375
376    /// Patches a `__vtable` member access into the given node, e.g. `ref^.foo()` becomes `ref^.__vtable^.foo()`
377    fn patch_vtable_access(&mut self, node: &mut AstNode) {
378        let old_base = node.get_base_ref_expr_mut().unwrap(); // `ref^` in `ref^.foo()`
379
380        let mut new_base = AstFactory::create_deref_reference(
381            AstFactory::create_member_reference(
382                AstFactory::create_identifier("__vtable", SourceLocation::internal(), self.ids.next_id()),
383                Some(std::mem::take(old_base)),
384                self.ids.next_id(),
385            ),
386            self.ids.next_id(),
387            SourceLocation::internal(),
388        );
389
390        std::mem::swap(old_base, &mut new_base);
391    }
392
393    /// ref^.__vtable^.foo()` -> `__vtable_{POU_NAME}#(ref^.__vtable^).foo()
394    fn patch_vtable_cast(&mut self, node: &mut AstNode, pou_type_name: &str) {
395        let base_old = node.get_base_ref_expr_mut().unwrap(); // `ref^.__vtable^` in `ref^.__vtable^.foo()`
396        let base_old_paren = AstFactory::create_paren_expression(
397            std::mem::take(base_old),
398            SourceLocation::internal(),
399            self.ids.next_id(),
400        );
401
402        let mut base_new = AstFactory::create_cast_statement(
403            AstFactory::create_member_reference(
404                AstFactory::create_identifier(
405                    format!("__vtable_{pou_type_name}"),
406                    SourceLocation::internal(),
407                    self.ids.next_id(),
408                ),
409                None,
410                self.ids.next_id(),
411            ),
412            base_old_paren,
413            &SourceLocation::internal(),
414            self.ids.next_id(),
415        );
416
417        std::mem::swap(base_old, &mut base_new);
418    }
419
420    // `__vtable_{POU_NAME}#(ref^.__vtable^).foo()` -> `__vtable_{POU_NAME}#(ref^.__vtable^).foo^()`
421    fn patch_method_call_deref(&mut self, node: &mut AstNode) {
422        let mut base_new = AstFactory::create_deref_reference(
423            std::mem::take(node),
424            self.ids.next_id(),
425            SourceLocation::internal(),
426        );
427
428        std::mem::swap(node, &mut base_new);
429    }
430
431    /// Casts the instance argument to its concrete type, as defined by the method. While not strictly
432    /// necessary, because the code would compile without this step, it is required when generating IR using
433    /// the `--ir` flag. This is because some type-validation happens (afaik).
434    ///
435    /// For example `alpha(1, 2)` will be transformed into` `<...>.alpha^(A#(THIS^), 1, 2)` instead of
436    /// `<...>.alpha^(THIS^, 1, 2)`. The same would be true for `refInstance.alpha(1, 2)` which would become
437    /// `<...>.alpha^(A#(refInstance), 1, 2)`.
438    /// ```text
439    /// FUNCTION_BLOCK A
440    ///     METHOD alpha
441    ///         VAR_INPUT
442    ///             a, b: DINT;
443    ///         END_VAR
444    ///     END_METHOD
445    /// END_FUNCTION_BLOCK
446    ///
447    /// FUNCTION_BLOCK B EXTENDS A
448    ///     METHOD bravo
449    ///         alpha(1, 2);
450    ///     END_METHOD
451    /// END_FUNCTION_BLOCK
452    /// ```
453    fn maybe_cast_instance(&mut self, operator: &AstNode) -> AstNode {
454        let Some(method_owner) = self
455            .annotations
456            .get_type(operator, self.index)
457            .map(DataType::get_type_information)
458            .and_then(DataTypeInformation::get_method_owner)
459        else {
460            return operator.get_base_ref_expr().unwrap().clone();
461        };
462
463        let base = operator.get_base_ref_expr().unwrap();
464        AstFactory::create_cast_statement(
465            AstFactory::create_member_reference(
466                AstFactory::create_identifier(method_owner, SourceLocation::internal(), self.ids.next_id()),
467                None,
468                self.ids.next_id(),
469            ),
470            AstFactory::create_paren_expression(base.clone(), SourceLocation::internal(), self.ids.next_id()),
471            &SourceLocation::internal(),
472            self.ids.next_id(),
473        )
474    }

482    fn lower_statements(source: impl Into<SourceCode>, pous: &[&str]) -> Vec<String> {
483        let (_, project) = parse_and_annotate("unit-test", vec![source.into()]).unwrap();
484        let unit = project.units[0].get_unit();
485
486        let mut result = Vec::new();
487        for pou in pous {
488            result.push(format!("// Statements in {pou}"));
489            let statements = &unit.implementations.iter().find(|it| &it.name == pou).unwrap().statements;
490            let statements_str = statements.iter().map(|statement| statement.as_string()).collect::<Vec<_>>();
491
492            result.extend(statements_str);
493        }
494
495        result
496    }
