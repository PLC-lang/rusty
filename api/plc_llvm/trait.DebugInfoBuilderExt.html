fn enable_key_instructions(&self, function: FunctionValue<'ctx>)

Replaces the function’s subprogram by one that places is_stmt by Key Instructions (see InstructionValueExt::set_key_instruction). LLVM fixes this flag when it creates a subprogram, so call this before anything refers to the function’s subprogram.
