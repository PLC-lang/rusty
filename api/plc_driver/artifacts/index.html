Naming of the intermediate build artifacts (object, bitcode and IR files).

All artifacts of a build land in one flat directory. A layout that mirrors the source tree instead carries the full path of every source file into the build directory, and for sources outside of the project (libraries, for example) that path goes past the limits of the Windows file system.
