Crate plc_literals 

Source
Expand description

Allocation-free parsers for the Structured Text literal grammar.

The compiler’s lexer has already classified a token when these functions run; the standard library’s STRING_TO_* functions call them on raw runtime input. Both sides share one implementation, so a literal that compiles to a value converts to the same value at runtime.

Nothing here allocates or touches floating point: every result is exact.
