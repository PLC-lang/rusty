parse_integer
Parses an integer literal: [+-]? decimal or (2|8|16)# digits, with single underscores allowed between digits. The whole input must be consumed.
parse_real_as_integer
Parses a decimal real literal ([+-]? digits [. digits] [(e|E) [+-]? digits]) and returns its integer part, truncated toward zero. A plain decimal integer is accepted as well, so this is the one entry point for “a number, as the compiler would assign it to an integer”.
