Calendar literals (DATE, TIME_OF_DAY, DATE_AND_TIME): the body after the #.

Parsing only checks the shape (digits-digits-digits, digits:digits[:digits[.digits]]); whether the fields form a real calendar day or time of day is answered by the value methods, so the compiler can keep reporting syntax and range problems separately.
