# Reference

These pages are for looking things up, not for reading from the top. They list every option and subcommand of `plc`, every key of the project file, every language construct that the compiler accepts together with the ones that it does not, and the function families of the standard library with the file that declares each of them. The last page holds one entry per diagnostic code, with an example of the mistake and of the correct form, which is the same text that `plc explain` prints. The guide parts explain the concepts behind all of it.
