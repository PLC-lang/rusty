# Language Guide

This part explains Structured Text as this compiler accepts it, and the chapters build on each other, so read them in order the first time. The first group covers the ground: what a source file holds, how a variable is declared and initialized, and the types for numbers, text, time, and the structures that you build yourself. The middle group puts those to work with expressions, control flow, functions, and the function blocks and programs that keep their data between calls. The last group is about larger designs: methods and properties, inheritance and interfaces, generic functions, pointers, the binding of variables to hardware addresses, and bodies that are drawn as charts instead of written as text. Every chapter states what the compiler rejects as well, with the code of the diagnostic that it reports.
