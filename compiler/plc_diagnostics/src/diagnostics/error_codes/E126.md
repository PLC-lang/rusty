# Incompatible types in interface polymorphism

This error occurs when an assignment or call argument involves an interface type but the
source type does not satisfy the interface contract. There are three cases:

## Case 1: POU does not implement the interface

When assigning a concrete function block or class instance to an interface-typed variable
(or passing it as an argument), the POU must implement that interface — either directly
via `IMPLEMENTS` or transitively through its `EXTENDS` chain. A source that is not a POU,
such as a `DINT`, is reported the same way.

### Invalid

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

FUNCTION_BLOCK FbX
END_FUNCTION_BLOCK

FUNCTION main
    VAR
        instance : FbX;
        ref      : IA;
    END_VAR
    ref := instance;  // Error: FbX does not implement IA
END_FUNCTION
```

### Valid

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

FUNCTION_BLOCK FbA IMPLEMENTS IA
    METHOD foo END_METHOD
END_FUNCTION_BLOCK

FUNCTION main
    VAR
        instance : FbA;
        ref      : IA;
    END_VAR
    ref := instance;  // OK: FbA implements IA
END_FUNCTION
```

Implementation is also satisfied transitively through inheritance:

```st
FUNCTION_BLOCK FbA IMPLEMENTS IA
    METHOD foo END_METHOD
END_FUNCTION_BLOCK

FUNCTION_BLOCK FbB EXTENDS FbA
END_FUNCTION_BLOCK

FUNCTION main
    VAR
        instance : FbB;
        ref      : IA;
    END_VAR
    ref := instance;  // OK: FbB inherits IA implementation from FbA
END_FUNCTION
```

## Case 2: Interfaces are not related

When assigning one interface-typed variable to another, the source interface must be the
same as or extend the target interface. Downcasts (parent to child) and assignments between
unrelated interfaces are rejected.

### Invalid — downcast

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

INTERFACE IB EXTENDS IA
    METHOD bar END_METHOD
END_INTERFACE

FUNCTION main
    VAR
        refIA : IA;
        refIB : IB;
    END_VAR
    refIB := refIA;  // Error: cannot downcast IA to IB
END_FUNCTION
```

### Invalid — unrelated interfaces

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

INTERFACE IB
    METHOD bar END_METHOD
END_INTERFACE

FUNCTION main
    VAR
        refIA : IA;
        refIB : IB;
    END_VAR
    refIA := refIB;  // Error: IB and IA are not related
END_FUNCTION
```

### Valid — upcast

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

INTERFACE IB EXTENDS IA
    METHOD bar END_METHOD
END_INTERFACE

FUNCTION main
    VAR
        refIA : IA;
        refIB : IB;
    END_VAR
    refIA := refIB;  // OK: IB extends IA
END_FUNCTION
```

## Case 3: By-reference parameters and outputs

A `VAR_IN_OUT` parameter, a function or method `VAR_OUTPUT`, a `VAR_INPUT {ref}` parameter and a
`REFERENCE TO` an interface bind the caller's variable itself instead of a copy. A function block
output is copied into the caller's variable after the call, without conversion. The argument
must therefore be a variable of exactly the parameter's interface. An instance does not qualify,
even if it implements the interface, and neither does a variable of a child, parent or unrelated
interface. The same rule applies when only the argument is an interface, for example an interface
variable passed to a `VAR_IN_OUT` of a function block type, and to `rr REF= x` with
`rr : REFERENCE TO IA`. If the parameter or reference is a declared variable, the error is
followed by a note (E159) at its declaration.

### Invalid

```st
INTERFACE IA
    METHOD foo END_METHOD
END_INTERFACE

INTERFACE IB EXTENDS IA
    METHOD bar END_METHOD
END_INTERFACE

FUNCTION_BLOCK FbA IMPLEMENTS IA
    METHOD foo END_METHOD
END_FUNCTION_BLOCK

FUNCTION update
    VAR_IN_OUT
        ref : IA;
    END_VAR
END_FUNCTION

FUNCTION main
    VAR
        instance : FbA;
        refIB    : IB;
    END_VAR
    update(instance);  // Error: expected type 'IA' but received 'FbA'
    update(refIB);     // Error: expected type 'IA' but received 'IB'
END_FUNCTION
```

### Valid

```st
FUNCTION main
    VAR
        instance : FbA;
        refIA    : IA;
    END_VAR
    refIA := instance;
    update(refIA);  // OK: a variable of type IA
END_FUNCTION
```
