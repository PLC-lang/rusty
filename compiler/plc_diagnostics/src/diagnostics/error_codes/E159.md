# Argument Passed to a `REFERENCE TO` Variadic

A sized variadic parameter whose element type is `REFERENCE TO` an interface stores each argument by value
in a pointer-sized element. An interface reference, and the reference the compiler creates for an instance
of an implementing function block, do not fit that element, so the call is rejected instead of generating a
call that overruns its argument array.

Erroneous code example:

```iecst
INTERFACE IA
END_INTERFACE

FUNCTION_BLOCK FbA IMPLEMENTS IA
END_FUNCTION_BLOCK

TYPE RefIA : REFERENCE TO IA; END_TYPE

FUNCTION consume : DINT
VAR_INPUT
    rest : {sized} RefIA...;
END_VAR
END_FUNCTION

FUNCTION main
VAR
    instance : FbA;
    reference : IA;
END_VAR
    consume(instance);
    consume(reference);
END_FUNCTION
```

Declare the variadic by reference instead, which passes the address of each argument:

```iecst
FUNCTION consume : DINT
VAR_INPUT {ref}
    rest : {sized} IA...;
END_VAR
END_FUNCTION
```
