# Instance Passed to a `REFERENCE TO` Variadic

A sized variadic parameter whose element type is `REFERENCE TO` an interface takes interface references.
An instance of a function block that implements the interface cannot be passed to it: the reference the
compiler would create for the instance does not fit the pointer-sized element the variadic stores, so the
call is rejected instead of generating a call that overruns its argument array.

Erroneous code example:

```iecst
INTERFACE IA
END_INTERFACE

FUNCTION_BLOCK FbA IMPLEMENTS IA
END_FUNCTION_BLOCK

TYPE RefIA : REFERENCE TO IA; END_TYPE

FUNCTION consume : DINT
VAR_INPUT
    rest : {sized} RefIA...;
END_VAR
END_FUNCTION

FUNCTION main
VAR
    instance : FbA;
END_VAR
    consume(instance);
END_FUNCTION
```

Declare the variadic by reference instead, which passes the address of each argument:

```iecst
FUNCTION consume : DINT
VAR_INPUT {ref}
    rest : {sized} IA...;
END_VAR
END_FUNCTION
```
