# CFC action block without an instance

A block in a CFC network calls an action of a function block, but it names no
instance. The action runs on the data of one instance, so without one there is
nothing to call it on, and the block is rejected. Set the instance on the block
in the tool.

```
  counter.increment (1)     rejected: no instance
+-------------------+
| in            out |
+-------------------+

  inst : counter.increment (1)
+------------------------+
| in                 out |
+------------------------+
```

An action of a program needs no instance, because the program is its only
instance.

## Technical details

In the exported CFC file, the instance is the `instanceName` attribute of the
block. The block is rejected when its `typeName` names an action of a function
block and the attribute is missing:

```xml
<ppx:FbdObject xsi:type="ppx:Block" typeName="counter.increment" globalId="3">                     <!-- rejected -->
<ppx:FbdObject xsi:type="ppx:Block" typeName="counter.increment" instanceName="inst" globalId="3"> <!-- calls inst.increment -->
```
