# Unsupported CFC expression

A variable, source or sink element in a CFC network carries an expression that
is not supported. Only variable references (`foo`), qualified references
(`foo.bar`), indexed references (`arr[i]`) and literals (`5`) are allowed. A
source may also negate its value with a unary minus (`-foo`); a sink may not,
because it is the target of an assignment. Function calls and other
expressions are not allowed.
