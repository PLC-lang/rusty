# Unsupported CFC expression

A source or sink element in a CFC network carries an expression that is not
supported.

A source, including one that feeds a jump or a return, holds a value: literals
(`5`) and references (`foo`, `foo.bar`, `arr[i]`), combined by operators and
parentheses, such as `-foo`, `foo + 1` or `arr[i + 1] > 5`. A function call or
an assignment is not allowed anywhere in it, also not inside an index
(`arr[f()]`). Use a block element for a call and a sink element for an
assignment. The power operator `a ** b` is a call of `EXPT`, so use the `EXPT`
block instead. A list (`a, b`), a range (`1..5`), an empty text and a hardware
address (`%IX1.0`) are no single value and are not allowed either. The indices
of a multidimensional array (`grid[i, j]`) are allowed, and each one follows
the rule above.

A sink is the target of an assignment, so it holds a reference such as `foo`
or `arr[i + 1]`. A literal, an expression such as `-foo` or `foo + 1`, and a
reference in parentheses are not allowed.
