# Unsupported CFC expression

A variable, source or sink element in a CFC network carries an expression that
is not supported. The text of an element must be exactly one expression, so a
syntax error (`foo +`), text after the expression (`foo bar`), a list
(`foo, bar`), an assignment (`foo := 1`), or a part of an array literal such
as a range (`1..5`) or a multiplied element (`3(foo)`) is not allowed.

A source may hold any expression (`foo + 1`, `-foo`, `foo > 5`) except a
function call, such as `MAX(foo, bar)` or `foo + MAX(foo, bar)`, because a
call is modeled as a block element. This includes built-in functions such as
`SEL(g, foo, bar)` or `ADR(foo)`, and also applies to the source that feeds a
return or a jump.

A sink is the target of an assignment, so it may only hold a variable
reference (`foo`, `foo.bar`, `arr[i]`), without a call in its index.
