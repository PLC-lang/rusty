# Unsupported Syntax for the Chosen XML Target

The XML export target does not have a representation for the declared construct, so the project cannot
be written out without silently losing it.

The IEC 61131-10 schema used by Omron Sysmac Studio (`--xml-omron`) declares only four user defined type
specs: `StructTypeSpec`, `EnumTypeSpec`, `EnumTypeWithNamedValueSpec` and `ArrayTypeSpec`. There is no
spec for a pointer, so `POINTER TO` and `REFERENCE TO` cannot be exported.

Erroneous code example:

```iecst
TYPE MyPtr : POINTER TO INT; END_TYPE

PROGRAM mainProg
VAR
    value : MyPtr;
END_VAR
END_PROGRAM
```

To fix this, hold the value directly rather than pointing at it:

```iecst
PROGRAM mainProg
VAR
    value : INT;
END_VAR
END_PROGRAM
```

Aliases, subranges and strings have no spec either, but those are resolved to a plain type name at every
use site instead of being rejected, because the schema accepts arbitrary text in a `TypeName`. A pointer
has no such fallback.

This error is only raised for XML targets that cannot represent the construct. Compiling the same source
to an object file, or to an XML target whose schema supports pointers, is unaffected.
