# Duplicate CFC return pin

A block element in a CFC network carries more than one output pin with an
empty `parameterName`. An empty name marks the pin that receives the called
function's return value, and a function returns at most one value. Declared
`VAR_OUTPUT` pins always carry their parameter name.

```xml
<ppx:OutputVariables>
    <ppx:OutputVariable parameterName="">           <!-- the return pin -->
    <ppx:OutputVariable parameterName="">           <!-- a second one: rejected -->
    <ppx:OutputVariable parameterName="doubled">    <!-- a declared output -->
</ppx:OutputVariables>
```

Re-export the diagram from the IDE so the block matches the callee's signature.
