# Unsupported Syntax for the Chosen XML Target

The XML export target does not have a representation for the declared construct, so the project cannot
be written out without silently losing it.

Omron Sysmac Studio (`--xml-omron`) has no pointer type and no wide string type, so `POINTER TO`,
`REFERENCE TO` and `WSTRING` cannot be exported.

Erroneous code example:

```iecst
TYPE MyPtr : POINTER TO INT; END_TYPE

PROGRAM mainProg
VAR
    value : MyPtr;
    label : WSTRING[16];
END_VAR
END_PROGRAM
```

To fix this, hold the value directly rather than pointing at it, and use a single byte string:

```iecst
PROGRAM mainProg
VAR
    value : INT;
    label : STRING[16];
END_VAR
END_PROGRAM
```

Aliases, subranges, arrays and narrow strings have no user defined type spec either, but those are
resolved to a plain type name at every use site instead of being rejected, because the target accepts
arbitrary text in a `TypeName`. An array becomes `ARRAY[0..3] OF INT` and a string becomes `STRING[16]`.
A pointer and a wide string have no such fallback.

This error is only raised for XML targets that cannot represent the construct. Compiling the same source
to an object file, or to an XML target whose schema supports pointers, is unaffected.
