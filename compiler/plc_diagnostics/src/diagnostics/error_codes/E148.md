# E148 - Temporal literal overflow or underflow

This warning is emitted when a duration literal cannot be represented safely.

A `TIME` literal must not be negative, and neither a `TIME` nor an `LTIME` literal may exceed the
64-bit nanosecond range.

```iecst
VAR
    t  : TIME  := T#-1s;                                   // E148: TIME literal underflow detected
    lt : LTIME := LTIME#-1s;                               // fine, LTIME is signed
    o  : LTIME := LTIME#106751d23h47m16s854ms775us808ns;   // E148: LTIME literal overflow detected
END_VAR
```
