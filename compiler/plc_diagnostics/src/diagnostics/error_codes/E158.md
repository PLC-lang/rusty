# FUNCTION_BLOCK called without an instance

A `FUNCTION_BLOCK` is a type. A call must name a variable of that type. Calling the type itself is not a function call.

This also applies to aliases of a `FUNCTION_BLOCK` type. Declare an instance of the alias and call the instance.

Changing this diagnostic to a warning or ignoring it does not create an instance. Code generation still fails for a call that names only the type.

## Invalid

```iecst
FUNCTION_BLOCK fn_with_one_parameter
    VAR_INPUT
        in_one : DINT;
    END_VAR
END_FUNCTION_BLOCK

FUNCTION main : DINT
    fn_with_one_parameter(1);
END_FUNCTION
```

## Valid

```iecst
FUNCTION_BLOCK fn_with_one_parameter
    VAR_INPUT
        in_one : DINT;
    END_VAR
END_FUNCTION_BLOCK

FUNCTION main : DINT
    VAR
        inst : fn_with_one_parameter;
    END_VAR

    inst(1);
END_FUNCTION
```
