# Type name uses an internal prefix

Type names beginning with `__` use the prefix reserved for compiler-generated types.
Declaring one in a `TYPE` block produces a warning because it may collide with a type the compiler generates.

```iecst
TYPE __MyType : DINT;
END_TYPE
```

Rename the declaration to avoid the prefix. Referring to an existing internal type, such as
`__VOID`, does not produce this warning.
