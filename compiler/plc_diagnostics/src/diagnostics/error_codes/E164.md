# E164 - Implicit conversion between time or date and other types

The types `TIME`, `DATE`, `TIME_OF_DAY`, `DATE_AND_TIME` and their long variants do not convert implicitly
to numbers or to each other. Their values count in a unit that the number does not show. A long variant,
such as `LTIME`, is the same type as its short type and converts to it without a warning.

The warning is reported where such a value is assigned, and at the operand where a comparison, `MOD` or a
bitwise operation combines a time or date with another type.

Code example:

```iecst
PROGRAM mainProg
VAR
    duration : TIME;
    nanoseconds : LINT := 1500;
    expired : BOOL;
END_VAR
    duration := nanoseconds;              // warning
    duration := 5000;                     // warning
    expired := duration > nanoseconds;    // warning at nanoseconds
END_PROGRAM
```

To silence the warning, use a literal or a conversion function that names the unit:

```iecst
    duration := T#1500ns;
    duration := LINT_TO_TIME(nanoseconds);
    expired := duration > LINT_TO_TIME(nanoseconds);
```

Adding a number to a duration or subtracting one from it is reported by E157. Scaling a duration by a
number, such as `duration * 2` or `duration / 1.5`, converts nothing and is not reported.
