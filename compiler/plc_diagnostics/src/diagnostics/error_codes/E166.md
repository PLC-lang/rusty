# E166 - Unexpected signature of FB_EXIT with bInCopyCode

The method `FB_EXIT` declares the parameter `bInCopyCode`, but not in the form that the compiler
knows: `bInCopyCode` as the single input of type `BOOL`, and the return type `BOOL`. The method is
still called. The call that the compiler generates for the cleanup of an instance passes no
arguments and ignores the return value, so each parameter has the default value of its type or its
declared initial value.

Code example:

```iecst
FUNCTION_BLOCK Connection
    METHOD FB_EXIT: BOOL
        VAR_INPUT
            bInCopyCode: DINT;      // warning: BOOL is expected
        END_VAR
    END_METHOD
END_FUNCTION_BLOCK
```

Declare the parameter as the single `BOOL` input of a method that returns `BOOL`. The call that the
compiler generates passes `FALSE` for it:

```iecst
FUNCTION_BLOCK Connection
    METHOD FB_EXIT: BOOL
        VAR_INPUT
            bInCopyCode: BOOL;
        END_VAR
    END_METHOD
END_FUNCTION_BLOCK
```

Or declare the method with no parameters and no return type:

```iecst
FUNCTION_BLOCK Connection
    METHOD FB_EXIT
    END_METHOD
END_FUNCTION_BLOCK
```
