# RuSTy Documentation

This book has two parts.

- **User Documentation** explains how to install and use the compiler and how to write Structured Text programs for it.
- **Technical Documentation** explains how the compiler works internally: the stages of the pipeline, the participants that transform the program between stages, the alternative outputs, and the shared foundations that every stage builds on.

Start with the [Overview](technical/overview.md) if you want to understand the architecture.
